プライバシーポリシー

本ツールは、運営者本人の Google アカウントで認可を行い、Google の API を通じて、運営者自身のアカウントのデータのみを操作する個人用のものです。

  • 取得する情報：運営者本人の認可情報（OAuth トークン）のみです。第三者の個人情報は取得しません。
  • 保管：認可情報は運営者の非公開の設定に保管し、外部へ公開しません。
  • 第三者への提供：行いません。
  • Google API サービスのユーザーデータの取り扱いは、Google API Services User Data Policy（Limited Use 要件を含む）に従います。
  • 削除：Google アカウントの「サードパーティ アクセス」から、いつでも認可を取り消せます。
